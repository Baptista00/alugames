# AluGames - Locadora de Boardgames

Aplicação web desenvolvida em JavaScript que simula uma locadora de boardgames, permitindo alugar e devolver jogos de forma interativa.

## Funcionalidades

- Visualização de jogos disponíveis
- Botão para **alugar** jogos
- Botão para **devolver** jogos
- Contador de jogos alugados e devolvidos
- Atualização dinâmica da interface
- Manipulação de DOM com JavaScript

## Tecnologias utilizadas

- JavaScript
- HTML
- CSS

## Conceitos aplicados

- Manipulação de DOM
- Eventos (click)
- Estruturas condicionais
- Atualização dinâmica de elementos
- Lógica de controle de estado
